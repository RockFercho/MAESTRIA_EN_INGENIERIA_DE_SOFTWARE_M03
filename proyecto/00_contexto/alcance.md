# Alcance

## Dentro del alcance inicial

El sistema contempla:

- gestión de usuarios;
- gestión de profesionales;
- gestión de servicios ofrecidos;
- asociación de servicios con profesionales;
- configuración de horarios habituales de atención;
- registro de excepciones de disponibilidad;
- consulta de disponibilidad;
- registro de citas;
- reprogramación de citas;
- cancelación de citas;
- consulta de citas;
- gestión de estados de las citas;
- registro básico del historial de cambios de una cita;
- notificaciones internas relacionadas con eventos relevantes de una cita,
  consultables por el usuario autenticado;
- administración de parámetros operativos relacionados con las reservas;
- landing page informativa responsive, parte del mismo sistema, con
  consulta de información real desde el backend (servicios disponibles);
- restablecimiento seguro de contraseña iniciado por el administrador.

## Fuera del alcance inicial

No forman parte de la primera versión:

- historia clínica;
- diagnóstico o tratamiento médico;
- prescripción de medicamentos;
- facturación;
- contabilidad;
- procesamiento de pagos;
- videollamadas;
- telemedicina clínica;
- gestión de inventario;
- aplicación móvil nativa;
- integración directa con aseguradoras;
- inteligencia artificial para diagnóstico o atención médica;
- envío automático de correos electrónicos u otras notificaciones externas;
- recuperación automática de contraseñas mediante correo electrónico.
