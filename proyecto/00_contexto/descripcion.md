# Sistema Web de Gestión de Citas y Atención Virtual

El sistema permitirá a una institución gestionar la disponibilidad de sus
profesionales y ofrecer a sus usuarios un medio web para consultar horarios
disponibles, reservar, reprogramar y cancelar citas.

El personal autorizado podrá administrar profesionales, servicios, horarios
de atención, excepciones de disponibilidad y citas registradas. Asimismo,
podrá actualizar el estado de una cita durante su ciclo de atención.

El sistema deberá mantener consistencia entre la disponibilidad publicada y
las reservas realizadas, evitando que un mismo profesional sea asignado a
citas incompatibles en un mismo intervalo de tiempo.

La solución deberá contemplar tanto la gestión administrativa como la
interacción del usuario que solicita una cita, incluida la reserva en línea
mediante la aplicación web por usuarios autenticados, la cual formará parte
de la primera versión.

La primera versión incluirá, además, una landing page informativa
responsive —parte del mismo sistema— y notificaciones internas relacionadas
con los eventos relevantes de una cita, consultables por el usuario
autenticado. El envío automático de correos electrónicos quedará fuera del
alcance inicial.

## Objetivo del ejercicio

Diseñar progresivamente una solución de software justificable a partir de
requisitos funcionales, requisitos no funcionales y reglas de negocio,
utilizando agentes de inteligencia artificial como mecanismos de análisis,
validación y generación de propuestas.

Las decisiones finales de requisitos, arquitectura, base de datos e
implementación serán evaluadas y asumidas por el estudiante y no por el
agente.
